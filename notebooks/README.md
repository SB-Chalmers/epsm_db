# Exploration notebook

Open `explore_uddevalla.ipynb` after initializing and loading the dataset.
Select the project Python environment and set `UBEM_DATABASE_URL`.

Start with source loading states, then buildings, components, heights, addresses,
properties, certificates and statistical context. No manual SQL joins are needed.
Empty tables are interpreted alongside layer coverage. Export is an explicit action.

For fixture verification, set `UBEM_NOTEBOOK_DATASET` to the fixture dataset name.
