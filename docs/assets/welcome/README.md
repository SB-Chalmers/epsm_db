# README artwork

The light and dark header icons are unchanged 256 px exports from the
[canonical Pocket CAD icon pack](https://github.com/SB-Chalmers/epsm_studio/tree/main/design/pocket-cad/icons).
They use its MIT license; the local notice remains in [the brand directory](../brand/LICENSE).
The 64 px copies in `../brand/` remain available for compact documentation.

`logos.png` is the footer supplied by the project lead from
`renovation_catalogue/WP1A/figures/logos.png`. Organisation names and logos retain
their respective owners' rights; the software's MIT grant does not relicense them.

[manifest.json](manifest.json) records the source and SHA-256 of each copied
asset. Preserve these sources when replacing or redistributing the artwork.
